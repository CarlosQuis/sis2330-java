\# sis2330-java



Repositorio del curso de programación Java. Aquí se organizarán las actividades y los contenidos de las 16 semanas.



\## Plan de trabajo



| Semana | Tema |

|---|---|

| 01 | Introducción a Java |

| 02 | Variables y tipos de datos |

| 03 | Operadores |

| 04 | Estructuras condicionales |

| 05 | Estructuras repetitivas |

| 06 | Métodos |

| 07 | Arreglos |

| 08 | Matrices |

| 09 | Programación orientada a objetos |

| 10 | Clases y objetos |

| 11 | Encapsulamiento |

| 12 | Herencia |

| 13 | Polimorfismo |

| 14 | Clases abstractas e interfaces |

| 15 | Manejo de excepciones |

| 16 | Proyecto final |



\## Entorno de desarrollo



\- JDK 17

\- Maven 3.9

\- GHC 9.x



\## Estructura del repositorio



\- `src/`: código fuente del proyecto.

\- `semana01/` a `semana16/`: organización del curso.

\- `.gitignore`: archivos excluidos del control de versiones.
